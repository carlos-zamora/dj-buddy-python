# Web set editor (Phase 3)

The React + TypeScript + Vite set editor arrives with task **P3-1**. It will use:

- a TypeScript API client generated from the FastAPI OpenAPI schema with openapi-typescript,
- TanStack Query for data fetching,
- dnd-kit for drag-and-drop with keyboard reordering,
- Vitest, Testing Library and Playwright for tests, plus an axe accessibility scan of each page.

The folder holds nothing else until then.
